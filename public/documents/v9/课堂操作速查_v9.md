# 《小脑袋当队长》课堂操作速查

配套2026年10月9日晚批准的70—90秒有限片单、四步原生开场和六章无纸课堂。当前正式路线约75.8秒；K01字形未过，由教师讲述承接，不为凑量追加影片。学生无需学习单，以投影、原位口头交流、胸前手势和教师巡听完成活动。40分钟学习链和三次AI不变。下文“包内”均指 `离线课堂_v7_20261002`；v7只是保留的目录名。原固定私密站已成功发布当前路线与片尾修正版，原网址及仅本人范围不变；当前版本以包根说明和实际回执为准，不混用第64版历史状态。

## 先打开什么

1. 整包留在E盘或课堂数据盘，不拆散 `site`、`runtime` 和 `教师资料`。双击包内 `启动离线课堂.cmd`，它只后台启动本课堂，不自动开浏览器或全屏。
2. 同一浏览器、同一配置打开教师端 `http://127.0.0.1:8787/teacher` 和放映端 `http://127.0.0.1:8787/classroom/live`。只投影放映端；不要投影素材审阅、登录或教师审核页。两个窗口都用同一个地址，不混用不同域名、不同端口或无痕配置。
3. 联网课堂由教师在包内运行 `启动课堂.ps1 -实时AI`，服务端读取已安全配置的DeepSeek密钥；不把密钥填进网页、聊天或文档。默认启动器始终离线。若端口已占用，先查现有服务，不另起重复实例、不停止其他程序。
4. 课前检查旧进度；确需开始新课时，教师端点“开始新一轮上课／彩排”并确认。它只清本课匿名记录，但不能撤销，授课中不要误点。结束时双击“停止本课堂.cmd”，只停止经身份核对的本课堂服务。
5. 使用新片彩排时，在教师端“把故事接回真实活动”区勾选“启用新版故事彩排”。先重置新一轮，再勾选；新一轮默认关闭新候选。大屏始终留在连续放映页，不打开素材画廊。勾选不会替学生作答或解除活动条件；按钮灰色时先看下方说明，不为赶进度代勾学生完成。

原工程根目录的 `启动离线彩排.cmd` 是历史开发入口，不作为当前便携课堂包的推荐入口。课堂现场不安装依赖、不首次构建、不启动视频模型。

## 开场先讲清楚，再播放课堂片段

S01在教师端“开场故事教师推进”区依次点“1 · 封面”“2 · 认识小探”“3 · 发现问题”“4 · 一起行动”，放映端随之更新。先用约40—60秒讲清前因后果，小探身份介绍至少10秒：他是能出主意、找线索的AI小助手，但建议可能出错；他发现有些孩子先让AI完成作业、安排事情，自己还没想就照做；老师因此邀请他带来挑战包，大家要改游戏、查知识卡，再判断领奖信息。停在“AI帮忙出主意，谁来作决定？”让学生回应，导入整体仍占0—4分钟。

四步由教师掌握节奏，刷新保留本步；没有旧71秒影片结束锁。S01不播长导入，C03不播旧草稿转场，S25不播旧整理片，S26不播43.33秒长结尾。不要到历史审阅页补播这些片段。

## 正式六段在哪一刻播放

以下均为教师端按钮，学生原位讨论和胸前手势，不另加逐组操作。每片开始前结束上一步讲述；不要同时说话或另开有声播放器。影片播完回原活动页，再由教师接问，不把预录声音说成AI实时生成。

| 所在章节与按钮 | 何时能播、播完做什么 |
|---|---|
| S02“小探邀请补清游戏要求” | 在四对补要求前播放21.67秒连续双镜“游戏困惑—四卡展开”；接问“刚才的游戏还缺什么要求？”听四对实际要求。不要在180秒试玩中播放或算入游戏时间 |
| S02“试玩后采用”或“试玩后再改一处” | 完成180秒实际试玩、逐条对照、听理由并“记录本轮检查”后，只播本轮结论对应的一种；另一种应不可用。采用时指出符合哪条要求；再改时留下实际要改的一处，不预设成功 |
| C03“查证后回应” | 资料已出示，学生再次示意并说依据，教师“已听依据，确认知识卡”后播放，再把结论放回知识卡；电影册子不是科学来源 |
| S05“发现陌生附页” | 尚未公布安全做法时，先看陌生附页怎样出现；接问“这是谁给的，我们知道吗？” |
| S05“先问需要这些资料吗” | 完整看完发现镜后才可接播。停在待判断处，全班同看情境、胸前示意、说理由，不立刻播放安全结论 |
| S05“讨论核实后的安全回应” | 学生已讨论，教师核实并“公布安全做法”后才可播；回来落实“不填、不交，找老师或家长核实”，不尝试真实领奖表单 |

同一教师区有“暂停故事”“继续故事”“停音，返回活动”。返回活动中止当前片段，不会伪记完整播放；需要时重新播，不提前解锁隐私后续。换章或撤回当前成果会停旧片。刷新不自动重播：先核对当前场景，再点“继续故事”。浏览器拒绝有声自动播放时，教师在大屏点一次“点击播放”，不关闭浏览器安全策略。已有完整帧和声轨解码技术证据，不等于自然听感、无缝接缝或学校外放合格。

## 40分钟只走六章

| 时间与教师场景 | 学生做什么 | 教师最关键的操作与停点 |
|---|---|---|
| 0—4 · S01 召集令 | 认识小探，听为什么要一起改好挑战包，回答“AI都对吗” | 教师按四步原生介绍讲清身份、发现的问题、来意和行动；知识卡与陌生领奖附页后面才展开，不等旧长片结束 |
| 4—14 · S02 把话说清楚 | 八组原位看投影四项；邻近两组合成四对，各口述一条要求；真实试玩后核对 | 四对要求只录四次。请求第1次AI、私审、批准；核准安全后另启180秒，结束听依据并记录可用或要修改 |
| 14—24 · C03 判断与查证 | 10秒先想、胸前示意；看投影无答案三图；同桌说理由；再用资料核对 | 一次概括整体，不登记八组票。请求第2次AI的一条待查问题；30秒观察、30秒交流，听理由后才出示资料，再示意 |
| 24—29 · S05 隐私盾牌 | 全班比较陌生领奖与教师匿名创作，原位说理由、胸前示意 | 先比较两情境，不四对分格或逐组收票。实际讨论后“公布安全做法”：陌生表单不填、不交，找老师或家长核实 |
| 29—34 · S25 全班定稿 | 四对各留一句实际建议；全体核对、修改AI候选 | 只录四句匿名概括。请求第3次AI；教师批准候选后讨论，确认后保存定稿；可一键回看大字原话 |
| 34—40 · S26 授章与迁移 | 独立看同一投影图书角任务，同桌说行动和依据；每人只选一问口头表达，教师巡听、分享两份 | 先确认实际听到三类理由、口头出口和当前定稿，才进授章。最后70秒保留认可授章画面，教师回看本次定稿并收束，不追加片尾或第4次AI |

学生主要与老师和同桌交流，不排队到电脑，不要求八组分别操作网页。要求、理由与建议都取自当堂实际交流；没有听到的不代填，不预写成“全体已完成”。

## S02：三分钟是实际试玩，不是看动画

教师私屏先概括四对实际要求，选择对应选项；选项不合原意时先澄清，不能把教师补充说成学生原话。全班看投影中的角色、任务、条件、结果，教师选择四块积木，再收一个整体预测，不做纸卡拼搭。只用一个演示组代号，不轮换八个演示组。

点“③ 按本次要求生成实时方案”。私审三步是否合计180秒、每步含用时不超过20字、仅桌边已有物品和描述观察能完成，以及不离座、不触碰同学、人人能参与。依赖学习单、额外卡片或提前用查证图的方案不能批准。合格后点“批准后送往放映页”；不合格先改或用明确的离线示例。

在“实际试玩三分钟，再按要求检查”处勾选安全核准，再点“开始180秒实际试玩”。讲解、视频和AI等待都不计入；需要暂停点“暂停试玩”，回来点“继续余下试玩”。离开S02会暂停，刷新不补足未玩时间。结束时逐项对照并勾选已检查条件，听实际理由后勾选“已听到具体依据或一处修改建议”，再选择“目前符合要求，可用”或“发现问题，还要修改”，最后“记录本轮检查”。未完成实际核对时，记录及回应按钮应不可用；倒计时结束不等于游戏合格。

## C03：孩子去哪里查，什么时候看证据

无需发纸。教师收到本轮问题后在同一放映页展开三图，采用锁定Image 2观察图中的无答案区域，只有编号和“教学示意”标识，不提前显示科学结论。旧PDF仅可选备用；不剪成答案卡、不发旧S04证据卡，也不让孩子自行联网查。

教师控制顺序如下，均是一键推进全体，不逐组操作：

1. 教师讲述知识卡情境后，点“已讲述知识卡情境”，再“开始10秒独立思考”。当前不播放K01取册镜或旧草稿转场。八组胸前1指“同意”、2指“等等”、3指“要核对”，听一两条实际理由，不数票。
2. 只选一次实际整体信号，录一至两个不含个人信息的观察词。点“教师请求实时 AI 问题”；私屏把草案审成一个待查问题、不超过36字、不先说答案。点“批准给全班查看”，再在推进区点“显示审核后的AI问题”。
3. 点“看投影，30秒自己找”，全体看同一三图；结束点“30秒同桌交流”。让学生先指出真正看见的地方，不能把依偎图直接当成喂养方式的证明。
4. 听实际理由后，点“已听实际理由，出示核验资料”。资料就在同一放映场景，不要求另找设备；屏幕标明教师中文摘编及美国国家公园管理局《Bats》《Save the Bats!》来源。两篇来自同一机构，不称两家独立佐证。
5. 点“全班再次示意”，保持或修改都听依据；最后“已听依据，确认知识卡”。全体起初都答对也继续核对，不制造分歧、不强迫改判断。

网页失效时用包内 `教师资料/小脑袋当队长_六章静态应急课件_v9.pdf` 的查证部分，并按同目录教师使用说明推进。教师核验资料与无答案观察图分开，不把电影中的“资料来源”册子当科学证据。

## S05、S25、S26：少录入，保留学生决定

S05全班先看陌生领奖索取姓名、住址，再由教师切换到“由老师用小组代号请AI创作”的情境；教师读清用途和来源，同桌比较、胸前1指“可以说”、2指“要保护”，只听一两份理由，不逐组收票。先完成比较，再点“公布安全做法”并确认实际讨论，不先揭结论再切下一卡。合照与虚构人物可口头补问，旧四情境PDF只作备用。统一口令“停一停、不乱填、问一问”，不是少填一点就能提交。匿名代号和虚构人物只用于教师AI创作，不交给陌生领奖表单。

S25每对一句，四个输入框各最多12字。点“教师请求 AI 候选”；对照本轮四条实际建议，检查漏意、自增、重复或把操作说明当口诀。点“批准候选，供全班讨论”只是候选，不是定稿。学生修改后，勾“全班已讨论并确认这四句”，再“保存全班定稿”。“看大字原话”及“对照原话、AI候选、最终稿”只切视图，不替全体批准。原建议改变时旧候选和旧定稿撤回，需重新核对；不靠预录片代替这次成果。

S26不让学生点绿色徽章。教师听到投影图书角任务的三类行动与理由后，逐项勾“已听到这一项的行动和理由”；再点“三项理由已交流，显示出口表达”。每人只选一问，向同桌说“我会先……，因为……”，教师巡听、择两份分享，确认实际口头表达后才点“教师确认后进入授章画面”。每人的这一句只反映所表达的维度，不声称逐人掌握三项。38:50后留出最后70秒，在认可授章画面回看本次真实定稿、总结和过渡，不另找长结尾播放按钮。共同定稿或实际完成依据撤回，授章画面即退回迁移任务，须重新完成本轮确认，不能沿用旧成果授章。最后可收束：“AI能帮忙，但我们要先想、说清、找依据、保护信息，最后自己决定。”这是教师总结，不冒充全班本次共同定稿。

## 出错时不耽误整课

- AI等待占用对应时间段，不计试玩。教师以约20秒为单次课堂等待预算；超出或跑偏，点“取消本次草案”，再“使用离线示例”，明确说“现在看提前准备的离线示例”。离线例也要核对实际要求与原意，不伪称实时生成，不为演示强行增加第四次AI。
- 两窗不同步时先停播放，核对同一地址、浏览器配置和当前场景；不要在中途用“开始新一轮”修同步，以免清空真实进度。无法恢复就转静态PDF，实际要求与定稿写黑板。
- 视频无声、卡住或网页失败时立即停止旧声轨，按同源静态情境讲述；不同时开多个审阅播放器。只投影放映页，不把日志、登录页和密钥配置投影。
- 超时优先压缩重复讲述、重播与分享人数；保留180秒真实试玩、独立思考、资料核对、隐私判断和出口表达。40分钟是否可完成须由学校实走证明。
- 本任务每天17:30—23:00禁止视频制作和其他高负载工作。原工作日晚间及休息日禁止前台、全屏测试的边界继续叠加；此说明核对不代表已完成实机投影、自然听审或实体打印。
