# 小脑袋当队长：独立网页课堂

当前课堂采用单入口动态HTML，不另开教师控制台，也不混入编辑或历史审阅页。

- 当前正式入口：`public-v10/正式上课.html`，包含翻页、目录、分步、视频、输入和游戏。
- `public`保留旧版回退，不再进入当前部署。
- 静态公网不提供实时AI后端，示例会明确标注；完整实时AI请使用教师持有的本地联网启动器。
- 本仓库没有密钥、学生真实资料、本地服务端或运行程序。不要添加上述文件。
- 页面与媒体均为相对路径，不依赖外部字体或CDN。
- GitHub Pages不是国内托管，学校网络能否直连需教师自行尝试；不承诺全国网络可达。

发布仅手动触发，工作流只上传`public-v10`目录。当前为进度版，学校实课、外放与后排观看仍由教师模拟反馈。
